# Aaryan Thakare — Portfolio Website

A responsive single-page portfolio built with plain HTML, CSS, and JavaScript. No build tools or dependencies are required.

## Run on Windows
1. Extract `aaryan-portfolio-new.zip`.
2. Open the folder in VS Code.
3. Double-click `index.html` to open it in a browser, or use the VS Code Live Server extension.

## Before publishing
- Replace `aaryan.thakare@gmail.com` if needed.
- Replace the placeholder GitHub and LinkedIn URLs with your actual profile links.
- Update project links to the correct repositories or live demos.
- Add your resume PDF and point the Resume link to it.
- Edit the project descriptions and skills so they accurately represent your current work.

## Chatbot note
The portfolio chatbot is a front-end demo with predefined responses. It does not call a live AI model or require an API key. To add real AI responses, connect it to a backend and keep any AI provider API key on the server, never in browser JavaScript.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `README.md`, and the `assets` folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under build/deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site; the URL appears in Settings → Pages.
